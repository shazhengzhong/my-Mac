# Human IPA phoneme library

This directory contains human-recorded IPA phoneme audio used by the phonics page.

- Source: Yun-lab7/ipa-sound-lab audio directory
- Audio origins: Wikimedia Commons, spoken by people
- Audio licenses: mostly CC BY-SA 3.0; see `CREDITS.md`; the code license is separate (`CODE_LICENSE.txt`)
- Processing: OGG -> mono 22,050 Hz WAV, silence trimmed, cap 0.70 s, fade and normalize
- Diphthongs and rhotic combinations are composed from the base vowel recordings

If you redistribute the app, keep `CREDITS.md` with the audio files and comply with the
CC BY-SA 3.0 attribution/share-alike terms for the recordings.
