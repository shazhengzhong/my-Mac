# 英语口语练习 Android 壳

这是一个很小的 WebView 壳，不复制日记数据，只打开：

```
https://192.168.5.4:8443/
```

用途（华为/Android 没有真正的 PWA 独立窗口时）：

- 全屏打开，没有浏览器地址栏
- 按 Home/上滑回桌面后，回来保持当前页面
- 从最近任务里强制关闭后，再打开回到首页
- 支持录音测评所需的麦克风权限
- 支持 OCR 页面拍照或从相册选择图片
- 拍照/选图后进入裁剪页，可拖动方框选择识别区域，再交给网页上传

## 构建

```sh
./build.sh
```

工具链在 `toolchain/` 下（JDK 21 + Android SDK platform 35/build-tools 35）。
产物：

```
build/family-diary.apk
```

使用的是本机 debug keystore，仅用于家庭内安装，不要上架应用市场。

## 注意

- 手机必须和 Mac 在同一个 Wi-Fi，且 `https://192.168.5.4:8443` 可访问。
- 如果 Mac 的局域网 IP 变了，需要改 `MainActivity.java` 里的 `START_URL` 后重新构建。
- 录音第一次使用时会弹出麦克风权限。
- 打开 OCR 文件选择时会先选择“拍照”或“从相册选择”，选完图片进入裁剪页；拖动方框后点“完成”即可上传。
