# British IPA data

`britfone.main.3.0.1.csv` is the British English (RP / Standard Southern
British) pronunciation dictionary from
[JoseLlarena/Britfone](https://github.com/JoseLlarena/Britfone), version 3.0.1.

It is used only to display word-level British IPA. The app converts its strict
phoneme symbols and stress placement into the learner-facing IPA shown on the
word cards.
