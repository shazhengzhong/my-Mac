# 英语口语练习（English Speaking Practice）

给家人私用的英语口语练习网页：写中文日记，生成自然美式英文、单词级美式或英式音标，自己录音后回放对比。

> 当前阶段：**美音/英音总开关、拼读示范（音节/音素）、中英文对照、全文朗读卡拉 OK、查词、单词点击发音、拍照识别（腾讯云 OCR）、真实单词测评（腾讯 SOE）已可用**。
> 正式部署尚未接入；只做单词级发音测评，不做整句自动评分或自动纠音建议。

## 已实现

### 账号与隐私

- 家庭管理员初始化
- 手机号作为账号名 + 密码登录（不发送短信）
- 管理员生成一次性家庭邀请码
- 通过邀请码加入家庭
- 一次性恢复码重置密码，不依赖短信或邮箱
- 修改密码后其他设备自动退出
- 登录失败 5 次后暂时锁定
- 普通成员不能访问管理员页面
- 管理员只能看到成员显示名，不能查看成员内容

### 日记、翻译和音标

- 每位成员的新建、查看、编辑、删除只作用于自己的日记
- 中文日记保存后才调用翻译，翻译失败不会丢失中文
- 默认使用 mock 模拟翻译，不联网、不花钱
- 已写好 DeepSeek 翻译适配器，但真实调用默认关闭
- 每次翻译或手动修改英文都会创建新版本，旧版本保留
- 英文按句子拆分，逐词显示当前选择的美式或英式 IPA 与重音
- 每个单词可打开拼读示范：按音节或音素逐个听，再回到整词
- 词典未收录的单词明确显示“未收录”，不会让 AI 乱猜
- 可以为每句话手动校正音标；美音和英音分别保存
- 修改中文后，旧英文会显示“可能过时”提示
- 每天翻译次数上限（默认 20 次）

### 美音 / 英音总开关

顶部导航有「发音：美音 / 英音」总开关，每位家庭成员分别保存自己的选择：

- 切换后，日记逐词音标、查词结果和音标校对页都会使用所选口音
- 单词发音、句子示范和全文朗读也会使用对应口音的音色
- 美音 IPA 来自 CMUdict；英音 IPA 来自 Britfone（RP，约 16,000 词，MIT 许可）
- 英音词典没有收录时显示「英式音未收录」，可手动填写；美音和英音的人工校正互不覆盖
- 全文朗读按「版本 + 速度 + 口音」分别缓存，切换口音不会误用另一种口音
- 腾讯 SOE 单词评分使用通用英语引擎，不区分美音/英音

### 示范朗读与录音

- 每句可生成“正常”和“慢速”两种示范音频
- 示范音频使用火山引擎豆包 TTS；把 `TTS_PROVIDER` 改成 `mock` 时会退回模拟提示音，不联网、不产生费用
- 示范音频按句子缓存，重复播放不重复扣额度
- 每天有 TTS 字符额度（默认 5,000 字符）
- 网页内麦克风录音，最长 60 秒
- 浏览器先把录音转换为 16 kHz 单声道 WAV
- 录音和示范音频都只允许本人访问
- 服务端支持 Safari 所需的 HTTP Range 播放
- 删除日记时，关联的录音和示范音频文件会一起清理

## 第一次使用

### 1. 进入项目

打开 Mac 的“终端”，执行：

```bash
cd /Users/shazhengzhong/Downloads/diary-pronunciation-coach
source .venv/bin/activate
```

### 2. 创建家庭和首位管理员（只需一次）

```bash
python manage.py bootstrap_family
```

按提示输入家庭名称、手机号、显示名和密码。输入密码时屏幕不会显示字符，这是正常的。

命令只会运行一次；成功后打印 **10 个一次性恢复码**。请立刻抄写或存入密码管理器，关闭后无法再次显示。

### 3. 启动网站

```bash
python manage.py runserver 127.0.0.1:8000
```

在浏览器打开：

```text
http://127.0.0.1:8000/
```

目前只在本机可用；给家人手机使用需要后续部署 HTTPS。

### 4. 邀请家人（当前本机可先验证页面）

1. 管理员登录后点击“邀请家人”
2. 输入家人的手机号
3. **马上复制只显示一次的邀请码**并单独发给对方
4. 家人在 `http://127.0.0.1:8000/accounts/join/` 输入邀请码、手机号、名字和密码

## 翻译模式

### 默认：模拟翻译

`.env` 里的相关设置现在是：

```text
TRANSLATION_PROVIDER=mock
```

它只用于开发测试，不会联系 DeepSeek，也不会产生费用。

### 真实 DeepSeek（已验证启用）

首次真实短文本测试已于 2026-10-27 通过：0.52 秒返回自然美式英文，用量 103 tokens。

准备好 API Key 后，由你本人编辑本机 `.env`：

```text
TRANSLATION_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的真实密钥
DEEPSEEK_MODEL=deepseek-chat
```

注意：

- 不要把 API Key 发到聊天、截图或公开仓库。
- 开启后，每篇翻译请求会把中文日记发送给 DeepSeek。
- 每日次数上限由 `TRANSLATION_DAILY_REQUEST_LIMIT` 控制。
- 真正开启前应先取得明确同意，并先用一句短文本验证。

## 中英文句子对照

重新翻译后，页面**顶部直接显示「日记对照」阅读区**，下面保留练习/测评区：

- 中文在上、英文在下
- 一句中文翻成多句英文时，多句英文归到同一句中文下面
- 右上角有「**双语 / 只中文 / 只英文**」三档切换：
  - 只英文：隐藏所有中文，适合朗读
  - 只中文：隐藏整个英文练习区，只看中文
  - 双语：中文和英文都显示
- 浏览器会记住上次选择
- 练习区每句英文上方也会显示对应中文
- 旧版本和手动修改的英文没有对照信息，页面会提示重新翻译；旧版本会保留

## 全文朗读与卡拉 OK 字幕

「日记对照」阅读区顶部有「全文朗读」按钮和速度选择：

- 速度可选「正常 / 慢速」：正常 `-20`，慢速 `-35`
- 两个速度分别生成、分别缓存，互不重复扣费；浏览器记住上次选择
- 播放时逐词高亮：已读过的词变绿，当前词黄色
- 第一次点击生成并缓存整篇音频和逐词时间戳；同一版本、速度、口音再次点击直接使用缓存
- 音频和字幕时间轴按版本、速度、口音保存；重新翻译后需要重新生成
- 中文不朗读（当前只有英文音色），中文保留在上方作为对照
- 全文朗读计入每日 TTS 字符额度 `TTS_DAILY_CHAR_LIMIT`
- 实测 v8：220 字符、43 个词；正常 15.5 秒，慢速 18.4 秒；每个速度约 0.066 元
- 如果字幕时间轴和页面词数不一致，页面只播放音频并提示，不会错位高亮

### 真实火山 TTS（已试听通过）

适配器已按火山引擎豆包语音 V3 HTTP SSE 接口实现，并用真实账号完成一句试听。本机 `.env` 已启用真实语音。

```text
TTS_PROVIDER=volcengine
# 新版控制台（推荐）
VOLCENGINE_API_KEY=你的密钥
# 或者旧版控制台
# VOLCENGINE_APP_ID=你的 App ID
# VOLCENGINE_ACCESS_TOKEN=你的 Access Token
# 美音女声
VOLCENGINE_TTS_VOICE=en_female_hayley_uranus_bigtts
# 英音女声；留空会回退到美音音色
VOLCENGINE_TTS_VOICE_UK=en_female_authoritative-british_uranus_bigtts
VOLCENGINE_RESOURCE_ID=seed-tts-2.0
VOLCENGINE_TTS_NORMAL_SPEECH_RATE=-20
VOLCENGINE_TTS_SLOW_SPEECH_RATE=-35
```

注意：

- 2.0 音色必须以 `_uranus_bigtts` 结尾，并配 `seed-tts-2.0`；1.0 音色配 `seed-tts-1.0`。不匹配会报 `55000000`。
- 英音音色 `en_female_authoritative-british_uranus_bigtts` 已用真实火山 TTS 合成 `water` 验证通过（约 1.25 秒音频）。
- 本机实测正常语速 `-20` 约 1.5 倍时长，用户确认合适；慢速 `-35` 待试听。
- 网页流程已验证：生成、播放、缓存和每日额度正常；第二次点击同一句不会重复计费。
- 语速会进入缓存键，调整语速后不会复用旧音频。
- 每日字符额度由 `TTS_DAILY_CHAR_LIMIT` 控制。
- 凭据只写在 `.env`，不要发到聊天或截图。

## 单词点击发音

练习区每个单词都可以点击播放发音，单词后面有一个小小的 ▶。

- 使用火山 TTS，和整句示范朗读使用当前口音的音色
- 第一次点击会生成并缓存，约 0.5–1 秒；同一账号同一单词以后直接播放缓存，不重复计费
- 单词发音默认语速 `-20`（更慢），可用 `VOLCENGINE_TTS_WORD_SPEECH_RATE` 单独调整，不影响整句语速
- 多音节单词下方显示音节拆分，例如 `wa·ter`、`com·fort·able`；单音节词不重复显示
- 对 `I'm`、`they` 这类单独朗读容易出错的词，会自动附带一句上下文引导发音
- 单词发音计入每日 TTS 字符额度 `TTS_DAILY_CHAR_LIMIT`
- 如果 `TTS_PROVIDER=mock`，播放的是模拟提示音，不联网、不花钱
- 浏览器禁止自动播放时，会在单词下方显示一个手动播放器

## 查词

顶部导航「查词」进入独立查词页：

- 输入一个英文单词，显示中文释义、词性、当前选择的音标和音节拆分
- 美音来自 CMU 词典，英音来自 Britfone；音节来自本地词典；词典未收录时会明确显示「未收录」
- 点单词播放发音，使用火山 TTS 单词缓存；第一次约 0.5–1 秒，之后直接播放缓存
- 「拼读示范」可查看音节、音素和 IPA，并播放音节拼读/自然拼读
- 「录音测评」复用单词测评服务；本机已启用真实腾讯 SOE
- 新单词的释义会调用 DeepSeek 并缓存；查过的词不再重复收费；新词计入每日翻译次数上限
- 实测 `comfortable`：adj. 舒适的，`/ˈkʌmfərtəbəl/`，`com·fort·able`，发音 963 ms，约 0.0033 元

## 拍照识别

顶部导航「拍照识别」或「我的日记 → 拍照识别」进入：

1. 选择或拍摄一张英文书页、练习纸、菜单等照片（JPG / PNG / BMP，最大 5MB）
2. 腾讯云 OCR 识别文字，页面把结果放进一个可编辑的文本框
3. 先校对错字母、错标点；可以保留段落，也可以每句一行
4. 点「翻译成中文并生成练习」，DeepSeek 逐句翻译成中文，并创建一篇只属于你的「拍照识别」日记
5. 生成后直接复用现有练习区：中英文对照、单词点击发音、单词测评、全文朗读

注意：

- 每张照片算一次腾讯云 OCR 调用；`OCR_DAILY_REQUEST_LIMIT` 默认每天 10 张
- OCR 原图只用于当次识别，**不会作为日记附件保存**；识别出的英文和中文会保存为日记
- 照片会发送给腾讯云 OCR；页脚和上传页都有提示
- iPhone 如果上传 HEIC 失败，请把相机格式改为「兼容性最佳」，或先截图再上传
- OCR 可能识别错，生成前务必在校对页修改

本机实测（2026-10-28）：用一张包含 3 行英文的测试图完成真实腾讯云 OCR，识别结果正确；随后用 DeepSeek 翻译并生成 5 句中英文对照日记，流程通过。测试套件强制 mock，不会在 `manage.py test` 时调用付费服务。

## 拼读示范

日记练习区每个单词旁边有「拼读」链接，查词结果里有「拼读示范」按钮。打开后是一个单词页：

- 大号单词按音节变色，例如 `wa`（蓝）+ `ter`（红）
- 显示音节卡 `wa`、`ter`
- 显示当前口音的 IPA，例如美音 `/ˈwɔtər/`、英音 `/ˈwɔːtə/`
- 显示音素卡，例如美音 `w` `ɔ` `t` `ər`，英音 `w` `ɔː` `t` `ə`
- 底部有三个按钮：**整词发音**、**自然拼读**、**音节拼读**

音频说明：

- **音节拼读**：用现在的自然语音按「wa. ter. water.」生成并缓存；计入 TTS 字符额度
- **自然拼读**：逐个播放真人音素录音，再播放整词的自然发音；音素录音来自 Wikimedia Commons 的真人 IPA 录音库（CC BY-SA 3.0，署名和来源见 `services/data/phonemes/CREDITS.md`），会和整词自然音色不同
- **整词发音**：使用火山自然语音；第一次生成计入 TTS 字符额度，之后缓存
- 音素录音随项目分发，不联网、不产生额外 TTS 费用
- 拼读页会跟随导航里的美音/英音总开关；两种口音的音素/音节音频分别缓存

音素录音已经转换为本地 WAV，并做过静音裁剪、0.7 秒上限、淡入淡出和音量归一化；双元音由两个真人元音录音交叉淡化合成。

## 单词发音测评

每个单词旁边有「测评」按钮：点击后朗读 3 秒，自动停止并上传，页面显示准确度和综合得分。

- 默认 `ASSESSMENT_PROVIDER=mock`：返回固定分数，不联网、不花钱，用来检查界面。
- 本机已切换为 `ASSESSMENT_PROVIDER=tencent`，使用腾讯云口语评测（新版 SOE-N），只做单词级，不做整句评分或自动纠音建议。
- 单词录音会发送给腾讯云评分；整句录音仍然只保存在本项目服务器。
- 2026-10-28 真实测试：首次购买前腾讯返回 **4004 资源包耗尽**；购买额度后，用 `water` 的 16 kHz 测试音频通过 App 真实测评，返回综合 **96.7**、准确度 **96.7**、流畅度 **0.934**、完整度 **1.0**，并成功保存私有录音和测评记录。

真实评测配置（由你本人编辑 `.env`）：

```text
ASSESSMENT_PROVIDER=tencent
TENCENT_SOE_APP_ID=你的腾讯云 AppID
TENCENTCLOUD_SECRET_ID=你的 SecretId
TENCENTCLOUD_SECRET_KEY=你的 SecretKey
TENCENT_SOE_ENGINE=16k_en
TENCENT_SOE_SCORE_COEFF=1.0
ASSESSMENT_DAILY_REQUEST_LIMIT=30
```

注意：

- 腾讯云口语评测基础版已停止新购，必须用新版 SOE（WebSocket）。
- 新版没有免费调用额度；费用参考：后付费约 5 元/千次；套餐 9.9 元/万次（限时，仅可购 1 个，有效期以购买页为准）。一次单词测评算 1 次调用。
- 首次真实测评只测一个单词，确认分数和费用后再继续。
- SecretId/SecretKey 只写 `.env`，不要发到聊天或截图。

## 怎样试录音和示范朗读

1. 启动本地网站并登录
2. 打开一篇已经有英文的日记
3. 点击某句的“生成正常示范”或“生成慢速示范”
   - `TTS_PROVIDER=volcengine` 时会调用真实火山语音，生成英文人声并消耗字符额度
   - `TTS_PROVIDER=mock` 时只会生成一段短提示音，不联网、不花钱
4. 点击“开始录音”，浏览器会请求麦克风权限
5. 朗读该句，再点“停止录音”
6. 页面转换并上传 WAV 后会自动刷新，录音会出现在同一句下方
7. 使用两个音频播放器对比示范音和自己的录音

本机 `127.0.0.1` 属于浏览器认可的安全环境，因此 Mac 上可以测试麦克风。正式给手机使用时必须部署 HTTPS。

> Safari 26 的 MediaRecorder 在小时间切片下会生成空 Blob，页面会误报“没有录到声音”。前端已改为停止时直接取一个完整录音 Blob，不再使用 250 ms 小切片；如果仍看到旧行为，请用 `⌘⌥R` 强制刷新页面，清除缓存的旧脚本。

## 重要限制

- 手机号没有短信验证，只是登录账号名；加入由一次性家庭邀请码控制。
- 如果所有恢复码都丢失，账号无法通过应用找回。
- 应用内可以保证家人之间不可见；拥有服务器最高权限的人仍能读取数据库和音频文件。
- 美式/英式音标都是**单词级宽式标准音标**，不是整句连读、弱读的语音学转写。
- 同形异音词（例如 read 的两种时态读音）使用词典首选发音，可通过“校对音标”手动修改。
- 英音词典约 16,000 词，生僻词可能显示“英式音未收录”；腾讯 SOE 评分不区分口音。
- 拼读音素使用独立的真人录音库，和整词自然音色不同；音节和整词仍用自然语音。
- 只有 `TTS_PROVIDER=mock` 时示范音频才是模拟提示音；当前本机已启用真实火山语音。
- 拍照识别只支持 JPG/PNG/BMP；iPhone 的 HEIC 照片需要先改成「兼容性最佳」或截图。
- OCR 原图不会作为日记附件保存，但识别出的英文、中文和生成的练习会保存在本机数据库。
- 浏览器录音逻辑已经实现并通过服务器测试；Safari 26 的空 Blob 问题已改为停止时取完整 Blob 绕过，但还没有在 iPhone、安卓和华为上逐一实测麦克风。
- 目前只支持一个家庭；这是刻意的简化。
- 本机开发使用 HTTP；手机麦克风功能必须在正式 HTTPS 部署后才能测试。
